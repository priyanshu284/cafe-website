# 🦉 Owl Café Lucknow - Official Website

> **Lush Rooftop Café & Late-Night Hangout in Gomti Nagar, Lucknow**  
> *Open 24 Hours / Till 5 AM Daily • 4.4 ★ (1,144+ Reviews on Google)*

---

## 🌟 Overview

Owl Café is Lucknow's premier late-night rooftop sanctuary and specialty coffee lounge. Located in Vikaskhand 5 / Virat Khand, Gomti Nagar, this website delivers a seamless, modern experience for visitors to explore the menu, customize orders, reserve tables, and connect instantly via WhatsApp.

---

## ✨ Features

- **🌙 Midnight Luxury Rooftop Aesthetic:** Deep emerald & warm amber glow design with sleek glassmorphism and smooth micro-animations.
- **🍝 Interactive Signature Menu:** Filter by categories (*Pastas & Italian, Sizzling Starters, Chinese & Platters, Coffees & Shakes, Indian Mains & Burgers*).
- **🛍️ Live Order Tray & Bill Calculator:** Add items to a tray, manage quantities, calculate estimated totals, and send 1-click formatted order messages directly to WhatsApp.
- **📅 Table & Late-Night Party Reservation:** Complete booking form with seating preferences (Open Sky Rooftop, Indoor AC Lounge, Jam Session area) and instant confirmation popup.
- **⭐ Google Reviews Showcase:** Live-style 4.4 ★ rating breakdown based on 1,140+ reviews and verified customer testimonials.
- **📍 Location, Contact & Map:** Click-to-call (`084000 00042`), Instagram feed link (`@owllko`), and embedded dark-mode Google Maps.
- **📱 100% Responsive:** Optimized for mobile phones, tablets, and desktop displays.

---

## 🚀 Tech Stack

- **HTML5:** Semantic structure, SEO-optimized meta tags, OpenGraph.
- **CSS3:** Custom responsive layout, CSS variables, glassmorphism, animations.
- **JavaScript (Vanilla ES6):** Dynamic menu filtering, interactive tray cart system, modal dialogs, and WhatsApp link builders.
- **Icons & Fonts:** Font Awesome 6.5, Google Fonts (*Plus Jakarta Sans*, *Playfair Display*).

## 🌐 Quick Start

1. Clone or download this repository:
   ```bash
   git clone https://github.com/priyanshu284/cafe-website.git
   ```
2. Open `index.html` in any modern web browser or serve locally:
   ```bash
   python -m http.server 8080
   ```
3. Visit `http://localhost:8080` in your browser.
